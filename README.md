# Cloud-Based Job Portal and Recruitment Management System

## 1. Project Description

The Cloud-Based Job Portal and Recruitment Management System is a web application that connects students and recruiters on a single platform. Students can search for job opportunities, upload resumes and apply for jobs. Recruiters can post job vacancies and manage applications. AWS cloud services are used to host, store and monitor the application.

## 2. Problem Statement

Students often find it difficult to search for suitable job opportunities and track their applications. Recruiters also face challenges in managing multiple job applications manually. This project provides a common platform to make the recruitment process easier and more efficient.

## 3. Objectives

- To provide a platform for students to search and apply for jobs.
- To allow recruiters to post and manage job vacancies.
- To enable students to upload resumes and track applications.
- To simplify the recruitment process.
- To deploy the application using AWS cloud services.

## 7. AWS Services Used

1. Amazon EC2: To host and run the web application.
2. Amazon S3: To store student resumes and documents.
3. Amazon VPC: To create a secure cloud network.
4. Application Load Balancer: To distribute incoming user requests.
5. Auto Scaling: To automatically adjust the number of EC2 instances.
6. Amazon CloudWatch: To monitor application performance and server health.

## 8. Functionalities

### Student Module
- Student registration and login.
- Create and update profiles.
- Upload resumes.
- Search for job opportunities.
- Apply for jobs.
- Track application status.

### Recruiter Module
- Recruiter registration and login.
- Post job vacancies.
- Update and delete job postings.
- View student applications.
- Manage application status.

### Admin Module
- Manage student and recruiter accounts.
- Monitor job postings.
- Manage platform activities.
- View recruitment reports.

## 9. Expected Outcome

The system provides a simple and efficient platform for students and recruiters. Students can easily find job opportunities, while recruiters can manage vacancies and applications. AWS cloud deployment helps improve application availability, scalability and performance.

## 10. Conclusion

The Cloud-Based Job Portal and Recruitment Management System aims to simplify the recruitment process by connecting students and recruiters through a single platform. It also provides practical experience in web development, cloud computing and AWS deployment.
